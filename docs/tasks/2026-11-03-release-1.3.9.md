# v1.3.9 stable release

Release the current RC18-derived code, including the already validated CI baseline
repair and worker healthcheck change in PR #3. The stable release number was selected
explicitly; it is lower in version ordering than v1.4.0-rc.18 even though its code includes
later fixes. Do not rewrite previous release tags or assume an RC installation should
automatically switch to this version.

Package metadata, runtime version and the project lock entry must all agree. No
dependency versions change relative to the healthcheck branch. Keep the existing
RC17 withdrawal policy and frozen dependency install.

Verify local quality, the hosted main CI gate, reproducible archives, and the normal
tag-triggered image/updater/publication workflow. A production rollout is separate.
Review the [operator override migration](2026-11-03-worker-healthcheck.md) before rollout.
